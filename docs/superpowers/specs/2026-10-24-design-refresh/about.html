Spec: Process

A loop, not a line

  1. Listen

    Sit with the people who'll use it and find the part of their week that hurts.

  2. Define done

    Write down what finished looks like, and how we'll know it worked.

  3. Build with AI

    Build the smallest version that works, with AI doing the boring 80%.

  4. Ship

    Put it in front of real people quickly, even if it's rough.

  5. Watch

    See how it actually gets used, then go back and listen again.
